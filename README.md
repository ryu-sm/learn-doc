
## 2. テスト目的

DNS変更に伴う影響がないことを確認するため、対象となる4つのBotが変更後のURLで正常に呼び出され、実行を開始できることを検証する。





## 1. 要件背景

AsleadDNSから社内DNSへの移行に伴い、既存アプリケーションで使用している接続先URLを新DNSに対応したURLへ変更する必要がある。

本対応では、対象となる4つのBotの呼び出し先URLを変更し、DNS変更後も従来どおりBotを呼び出せるようにする。

また、URL変更による既存機能への影響を確認するため、対象4つのBotが正常に呼び出され、実行を開始できることを確認する。

なお、Botの実行結果確認および旧DNSの廃止に関する確認は、本対応のテスト対象外とする。





# DNS変更対応 テスト仕様書

## 1. テスト概要

- **対象案件**：SHODEVCP-38195
- **テスト対象**：4つのBot
- **テスト目的**：DNS変更に伴うBot呼び出しへの影響確認

## 2. テスト方針

DNS変更後のURLを使用し、対象4つのBotが正常に呼び出され、実行を開始できることを確認する。

なお、Botの実行結果確認および旧DNSの廃止に関する確認は対象外とする。

## 3. テストケース

| No. | テスト項目 | テスト内容 | 期待結果 |
|---|---|---|---|
| TC-01 | Bot①呼び出し確認 | 変更後のURLでBot①を呼び出す | 正常に呼び出され、実行が開始されること |
| TC-02 | Bot②呼び出し確認 | 変更後のURLでBot②を呼び出す | 正常に呼び出され、実行が開始されること |
| TC-03 | Bot③呼び出し確認 | 変更後のURLでBot③を呼び出す | 正常に呼び出され、実行が開始されること |

## 4. 判定基準

対象となる4つのBotすべてについて、呼び出しエラーが発生せず、実行開始が確認できること。

## 5. エビデンス取得方針

各Botの呼び出し成功および実行開始を確認できる画面、またはログを取得する。

Botの実行完了および処理結果に関するエビデンスは取得対象外とする。
