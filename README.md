# 1. テスト方針

## 1.1 テスト概要

### 案件背景

AsleadDNSから社内DNSへの移行に伴い、
ArgoCD管理対象の4つのPod／Serviceに関連する
DNS設定を変更する。

本テストでは、DNS変更後にArgoCD上で
対象リソースの設定が正しく反映され、
正常にデプロイ・稼働していることを確認する。

## 1.2 テスト目的

以下の事項を確認する。

1. DNS変更後、ArgoCDの同期状態が正常であること。
2. ArgoCDのヘルス状態が正常であること。
3. 対象となる4つのPodが正常に稼働していること。
4. 対象となる4つのServiceが正常に構成されていること。
5. DNS関連設定の変更が対象リソースに正しく反映されていること。

# 6. テスト実施方法

## 6.1 ArgoCD状態確認

1. ArgoCD管理画面にアクセスする。
2. 対象Applicationを選択する。
3. Sync Statusが「Synced」であることを確認する。
4. Health Statusが「Healthy」であることを確認する。

## 6.2 Pod稼働状態確認

1. ArgoCDの対象Applicationを開く。
2. 対象Podを確認する。
3. Podの稼働状態が「Running」であることを確認する。
4. PodのReady状態が正常であることを確認する。
5. 4つのPodについて同様に確認する。

## 6.3 Service状態確認

1. ArgoCDの対象Applicationを開く。
2. 対象Serviceを確認する。
3. Serviceの設定内容が設計と一致していることを確認する。
4. ServiceのSelectorと対象PodのLabelが一致していることを確認する。
5. 4つのServiceについて同様に確認する。

## 6.4 DNS設定反映確認

1. ArgoCDで対象リソースを確認する。
2. DNS関連設定の変更内容を確認する。
3. 変更後の設定値が設計内容と一致していることを確認する。
4. 対象4リソースについて同様に確認する。

※ DNS設定がConfigMap、Deployment等で管理されている場合は、
該当リソースの設定内容を確認する。

# 1. テスト方針

## 1.1 テスト概要

### 案件背景

現在、要員コスト管理システムでは、AsleadDNSを利用して各種サービスへのアクセスを行っている。

本対応では、AsleadDNSから社内DNSへの移行に伴い、DNS設定の変更、アプリケーションのアクセス先変更、および関連設定の修正を実施する。

本テストでは、DNS移行後も既存機能への影響がなく、各環境において新しいアクセス先から正常にサービスを利用できることを確認する。

## 1.2 テスト目的

以下の事項を確認する。

1. 社内DNSへの移行後、新URLからアプリケーションへ正常にアクセスできること。
2. 旧URLからのアクセスが、移行方針に従って制御されていること。
3. 新URLを利用した場合、既存のアプリケーション機能が正常に動作すること。
4. アプリケーションおよび関連サービスのDNS設定が正しく反映されていること。
5. テスト環境、ステージング環境、本番環境において、環境ごとの設定が正しく適用されていること。
6. DNS移行に伴い、既存機能に影響が発生していないこと。

# 7. テスト実施時の注意事項

## 7.1 旧URLアクセス確認

旧URLからのアクセスについては、移行方針を確認したうえでテストを実施する。

旧URLにSorryページを表示する仕様の場合、以下を確認する。

- 旧URLからアクセスした場合、指定されたSorryページが表示されること。
- Sorryページの表示内容が仕様どおりであること。
- 旧URLから意図せずアプリケーションを利用できないこと。

※ 旧URL廃止後の動作仕様が異なる場合は、確認内容を調整する。

## 7.2 環境別設定確認

以下の環境について、DNS設定の反映状況を確認する。

- UNIT環境
- テスト環境
- SEMI環境（ステージング環境）
- 本番環境

各環境の設定値およびアクセス先は、環境別の設計情報と一致していることを確認する。

## 7.3 リリース後確認

本番環境については、リリース手順および運用方針に従って確認する。

- 新DNS設定の反映確認
- 新URLからのアクセス確認
- 旧URLのアクセス制御確認
- 主要機能の動作確認

## 7.4 ノンデグレード確認

DNS移行によって既存機能に影響が発生していないことを確認する。

確認対象は、DNS変更の影響を受ける主要機能を中心とする。
